# Foysal Islam

Personal site for Foysal Islam, a web developer. A single-page portfolio with a geometric WebGL sculpture, original studies, and a private contact letter that is prepared in the browser and never stored.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

The visual language is non-figurative: geometry, type, and light. There are no photographs of people.
